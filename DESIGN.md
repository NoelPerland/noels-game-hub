# Noel's Game Hub design

- Role: let visitors choose and play nine original games or inspect available builds.
- Voice: game names, actual status and play action first; no implied live game where only source or a build exists.
- Type: bold arcade display, straightforward reading text and clear button labels.
- Color: dark arcade shell with neon cyan and pink reserved for focus and game art.
- Layout: genuine gameplay thumbnails lead each card. Status appears once; source links stay available when public.
- Motion: game-card feedback only; no decorative camera movement. Honor reduced motion.
